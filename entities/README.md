# Entity packages

One folder per business entity sharing portal 9201667. This is the context-layer home for
everything that describes an entity before, or beside, what the portal already holds; the
action layer (Hs-Logic) reads it and never writes to the production portal from it.

```
entities/<ENTITY>/
  sources/<name>.csv              raw external file: a HubSpot export from another portal, a Drive scan, a legacy dump
  sources/<name>.source.json      mapping spec generated by Hs-Logic (`python -m app.sources.cli match <ENTITY> <object> <csv> --save`
                                  or `POST /api/sources/match`), then reviewed and edited by hand
  schema.proposed.json            properties to create in the portal for the entity namespace, merged over all sources,
                                  including the system properties <entity>_source_key, <entity>_source_system, entity_scope
```

## Reviewing a `*.source.json`

Every column carries a `role` (`property`, `key`, `source_id`, `association`, `lookup`, `derived`,
`ignore`), a `decision` (`auto`, `review`, `manual`, `unmapped`, `ignored`), the target `property`,
a `transform` (`datetime`, `date`, `int`, `float`, `bool`, `phone`, `lower`) and the `evidence`
that produced the score. To override the machine: set `decision` to `manual`, change `property`
or `transform`, move a column into `derived[].columns`, or extend `key_columns`. `notes` list what
the matcher could not settle (Excel-mangled ids, owners given as names, missing pipelines).

## Loading

`python -m app.sources.cli load entities/<ENTITY>/sources/<name>.source.json --run-id <RunId> [--ingest-fake]`
writes the probe surface (`Hs-Logic/sampling/extract/<ENTITY>/<RunId>/`), an `import_plan.json`
(HubSpot batch payloads keyed by source key, applied later by mir-load or the Phase D apply step)
and a `load_report.json`. `pwsh sampling/run.ps1 -FileEntities <ENTITY>` runs the whole probe on it.
